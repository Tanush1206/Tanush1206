# Hi 👋, I'm Tanush Thakran

### Computer Science Undergraduate · Machine Learning · Data Science · RAG

I build **applied ML systems that are designed to be measured, evaluated, and shipped**.

My work focuses on **Machine Learning, Data Science, NLP, and Retrieval-Augmented Generation (RAG)** — from data ingestion and preprocessing to embeddings, retrieval, evaluation, APIs, and deployment.
